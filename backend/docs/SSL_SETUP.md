# Настройка SSL для API

## Обзор

Этот документ описывает, как настроить SSL/TLS для защищенного соединения с API.

## Конфигурация

SSL настраивается через переменные окружения или файл `.env` в корне проекта.

### Основные параметры

| Параметр | Описание | Значение по умолчанию |
|----------|----------|----------------------|
| `USE_SSL` | Включить/выключить SSL | `False` |
| `SSL_CERT_FILE` | Путь к SSL сертификату | `./certs/cert.pem` |
| `SSL_KEY_FILE` | Путь к приватному ключу | `./certs/key.pem` |
| `SSL_MIN_TLS_VERSION` | Минимальная версия TLS | `TLSv1_2` |
| `SSL_MAX_TLS_VERSION` | Максимальная версия TLS | `TLSv1_3` |

## Использование

### Включение SSL

Для включения SSL добавьте в файл `.env`:

```
USE_SSL=True
```

### Использование собственных сертификатов

1. Поместите ваши сертификаты в директорию `certs/` или укажите другой путь:

```
USE_SSL=True
SSL_CERT_FILE=/path/to/your/certificate.pem
SSL_KEY_FILE=/path/to/your/private_key.pem
```

### Автоматическая генерация сертификатов

Если SSL включен, но сертификаты не найдены, они будут автоматически сгенерированы при запуске сервера.

## Проверка настройки

Для проверки работы SSL:

1. Запустите сервер с включенным SSL:
```
USE_SSL=True python backend/main.py
```

2. Проверьте доступность API по HTTPS:
```
curl -k https://localhost:8000/health
```

## Рекомендации по безопасности

- В продакшн-окружении всегда используйте сертификаты от доверенного центра сертификации
- Регулярно обновляйте сертификаты
- Используйте TLS 1.2 или выше
